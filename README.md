# 🍋 柠檬账本 — Lemon Ledger

一个免费的个人记账 Web App，纯前端、iPhone 优先，适合由 Codex 根据中文需求持续迭代。

## 你可以怎样使用 Codex 修改
1. 解压 `柠檬账本-Codex项目.zip`，得到 `lemon-ledger` 文件夹。
2. 打开 Codex 桌面 App 或 Codex 的项目工作区，选择/打开此文件夹作为项目。
3. 在 Codex 中说：**“请先阅读 AGENTS.md 和 README.md，了解这个记账 App。今后我会用中文描述修改需求，请直接修改当前文件，并尽量保持旧数据兼容。”**
4. 然后直接说需求，例如：**“首页柠檬图片缩小 20%，输入框固定在下面，手机显示要更紧凑。请直接修改并告诉我如何预览。”**
5. 若 Codex 环境支持本地预览，要求它打开预览；否则照下方运行。

## 在 Mac 上预览
在项目文件夹打开终端，输入：

```bash
python3 -m http.server 8000
```

用浏览器打开 http://localhost:8000/ 。停止服务器按 Ctrl+C。`index.html` 也可直接浏览，但浏览器某些功能（特别是离线 PWA）可能受限制。

## GitHub Pages 发布
将本文件夹**内的文件**放在 GitHub 仓库根目录，设置 Settings → Pages → Deploy from a branch → main → /(root)。部署成功后打开 Pages 地址。更新代码后重新上传修改的文件即可。

## 现有功能
- 自然语言记录多笔消费与收入（规则识别；支持确认和编辑）
- 账单查询编辑、消费分类、统计图
- 每周/每月循环项目，打开 App 时自动补录
- 月预算、支付宝/微信/银行卡/现金等账户
- JSON 完整备份/恢复、CSV 交易记录导出
- 添加 iPhone 主屏幕（需 HTTPS 部署并使用兼容浏览器）

## 重要说明
- **数据保存在当前浏览器的 `localStorage` 中**，不同网址、不同设备的账本彼此独立。
- 升级代码前建议导出完整 JSON 备份；不要频繁清理浏览器网站数据。
- 基金定投记录为投资流出，不计入消费预算。
- 自动补录只是账本记录，不会真实扣除支付宝款项。
- 语音识别取决于浏览器，不保证所有设备都能用；并不承诺语音数据始终仅在本地处理。
- 没有服务器、账号系统、付费模型服务。

## 首页水果显示规则（V1.2）

- 当前自然月的**消费支出** < 5000 元：柠檬。
- 消费支出达到 5000 元且低于 10000 元：无花果（P1）。
- 消费支出达到 10000 元：番茄（P2）。
- 投资、收入不计入阈值。删账、改账及跨月后会重新计算。
- 水果容器 136×136 CSS 像素，窄屏 124×124，保留黑色投影。
- 请使用 Chrome / Safari 浏览器打开下载后的 HTML；ChatGPT 文件内置预览可能禁止脚本执行。
- 语音输入需要浏览器支持；不支持时可使用 iPhone 系统键盘上的麦克风。

### 固定项目统计说明
已到期的固定消费在打开 App 时补录为账单，计入实际消费统计；未到期的固定消费在「统计 → 固定项目与借款」单独列为预计，并显示已入账消费与预计的合计，避免重复计数。投资定投不计入消费。
